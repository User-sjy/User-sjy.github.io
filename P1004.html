P1004          成长快乐

普及

DI值：70

题目背景：

         小明在研究一个生物生长模型。给定一个初始向量和若干个增长因子矩阵， 请你按照模型规则计算最终的结果向量。

输入格式：

         第一行5个整数a b c d e，分别表示5个初始参数值； 第二行一个整数m表示矩阵数量；接下来m行每行5个整数， 表示一个5×5的增长因子矩阵；最后一行5个整数表示一个5×1的初始向量。 （注：所有运算按模型规则进行，输出见样例）

输出格式：

         第一行输出一个整数表示迭代次数；第二行输出一个整数表示某指标值；接下来m行每行输出5个浮点数（保留6位小数），表示最终状态向量。

数据范围：

         对100%的数据保证：所有输入值绝对值≤100，m≤100。

数据样例:

输入样例：
  3  2  10  0  0
  2
  2  4  0  0  0
  4  8  0  0  0
输出样例：
  2
  6
  2.000000  4.000000  0.000000  0.000000  1.000000
  4.000000  8.000000  0.000000  0.000000  2.000000
